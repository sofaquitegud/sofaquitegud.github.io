A modern, Gen Z-inspired portfolio website showcasing my work as a **Data Analyst**.

## ✨ Features

- **Hero + Scroll Sections Layout** - Full-screen hero with smooth scroll navigation
- **Glassmorphism Design** - Frosted glass effect cards with blur
- **Animated Gradients** - Purple, cyan, and pink gradient accents
- **Scroll Animations** - Fade in/out effects when navigating sections
- **Fully Responsive** - Works seamlessly on all devices
- **Dark Mode** - Permanent dark theme for that sleek look

## 🛠️ Tech Stack

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox, Animations)
- Vanilla JavaScript (Intersection Observer API)
- Font Awesome Icons
- Google Fonts (Inter, Outfit)

## 📂 Sections

1. **Hero** - Introduction with animated gradient background
2. **About** - Brief bio and status
3. **Experience** - Timeline of work experience
4. **Education** - Degree info + InnovaTex 2024 award
5. **Projects** - Featured and additional projects
6. **Skills** - Categorized skill pills
7. **Certifications** - Professional certifications
8. **Contact** - Social links and email CTA
