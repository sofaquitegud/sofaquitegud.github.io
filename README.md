# Muhammad Syafiq Farhan - Portfolio

A modern, responsive portfolio website showcasing my work as a Data Analyst & Analytics Engineer.

- **Bento Grid Layout**: Modern dashboard-style design
- **Dark/Light Mode**: Toggle between themes
- **Responsive Design**: Works on all devices
- **Interactive Elements**: Smooth animations and hover effects

## Technologies Used

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript
- Font Awesome Icons
- Google Fonts (Inter, Outfit)
